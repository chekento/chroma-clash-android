# Game Design Notes

## Core loop
1. Read A + X = Result.
2. Reconstruct X with the HSV picker.
3. Lock in before the timer expires.
4. Receive a CIEDE2000 ΔE verdict, grade, points and XP.
5. Build streaks, unlock achievements and climb 100 ranks.

## Long-term structure
- Standard Run: 10 rounds.
- Marathon: 25 rounds, unlocked at Rank 10.
- Endless: open-ended, unlocked at Rank 25.
- Adaptive difficulty scales timer and chromatic separation with career rank and run depth.

## Anti-grind principles
- Strong accuracy and difficult modes pay more than raw volume.
- Achievement rewards accelerate meaningful milestones.
- B-or-better streaks reward consistency.
- Daily streak counts only when a run actually starts.
- Aborted Standard/Marathon runs do not count as completed runs.
